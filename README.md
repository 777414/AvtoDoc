# AvtoDoc

Локальное Windows-приложение для автоматического формирования пакета документов курсантов автошколы.

## MVP

- Python + CustomTkinter
- Excel `.xlsx` / `.xls` как источник данных
- Word `.docx` как шаблоны
- Локальный Microsoft Office
- Результаты, шаблоны и логи рядом с `AvtoDoc.exe`

Спецификация MVP: v0.2.
